# Star Armory

A fan-made companion app for **Star Citizen**: blueprints, missions, mining, hauling, ships and a community feed in one place.

**[⬇ Download the latest version](https://github.com/excluesiive-cell/Star-Armory/releases/latest/download/Star-Armory.exe)** · [All releases](https://github.com/excluesiive-cell/Star-Armory/releases)

---

## What's inside

| | |
|---|---|
| **Star Blueprints** | Every crafting blueprint with its recipe, materials and quality. Track the ones you own and queue what you want to craft. |
| **Star Missions** | Missions from every faction with standing, reputation, rewards, blueprint drops and the full briefing. Filter by legal or illegal. |
| **Star Mining** | Where every ore spawns and how often, RS signatures, a rock breaker for your laser and modules, and mining missions split into hand, ROC and ship mining, with the best picks and a route from where you are. |
| **Star Refinery** | Refining yields by station and by ore, plus your refining orders with a reminder when they're done. |
| **Star Hauling** | Hauling missions with pay, reputation and cargo size, a mission route planner, best-mission picks and commodity trading. |
| **Star Port** | Ships, components and loadouts, with where to buy each part. |
| **Star Feed** | A small social space for pilots: news feed, groups for trading, mining, hauling, combat and more, friends, messages and notifications. |

## Install (Windows 10 / 11)

1. Download **Star-Armory.exe** from the link above.
2. Double-click it and choose **Yes** to install. It adds Start Menu and Desktop shortcuts.
3. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The app isn't code-signed yet, so Windows doesn't recognise it at first.

You can remove it any time from **Settings → Apps → Installed apps → Star Armory**.

## Updates

From **V4.8** onwards the app updates itself. It checks for a new version when it starts and every few hours, then shows an **Update available** card. Click **Update now** and it downloads, installs and restarts. Your settings, Star Feed login and saved data stay where they are.

Every update is signed by the developer and checked by the app before it installs. If anything about an update doesn't match, it's refused.

Already on an older version? Download the latest one above and run it once. After that, updates are automatic.

## On your phone

There's also a phone and tablet version that works on iPhone, Android and foldables. Ask in Star Feed for the link.
